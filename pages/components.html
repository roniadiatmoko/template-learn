Charts

Chart.js helpers in Lz.charts apply the theme colors, rounded bars, and dashed grid. Load Chart.js before lz.js. Colors follow light/dark mode when the page loads.

Theme, ripple, and hover

Small behaviors that apply to the whole theme.

Dark mode

The choice is stored in localStorage (lz.theme). Values: light, dark, auto (follows the system). Try the Light / Dark switch at the top of this page.

Code only. Open the JS tab.

Ripple

Buttons, menus, tabs, chips, and other clickable items show a ripple at the click point. To add it to a new element, add its selector to the RIPPLE list in lz.js. To turn it off for one element, add data-no-ripple. It is off when the system asks for reduced motion.

Hover and focus

For custom components use the same tokens so they match: background: var(--lz-hover) and color: var(--lz-primary-ink) on hover, and box-shadow: var(--lz-focus) on :focus-visible. Do not underline links.
