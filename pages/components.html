Collapsing the sidebar

The round chevron button on the right edge of the sidebar (half on the sidebar, half on the content, wide screens only) shrinks the sidebar to an icon rail, and the choice is remembered. On the rail, each level 1 item shows only its icon, with its name as a tooltip. Clicking a menu with sub-items widens the sidebar and opens that branch. Give every level 1 item an icon, because the text is hidden on the rail. Keep theme-init.js in <head> so the saved state applies before the page draws.

Code only. Open the CSS tab.

Sidebar menu (up to 3 levels)

The sidebar is rendered by layout.js from the MENU array. An item with children becomes a dropdown, and children can have their own children, down to level 3. Level 1 items use key (the page's data-page); level 2 and 3 items are matched by URL. The branch that holds the current page opens by itself, and the choice of open branches is remembered.

Card stack carousel

Cards pile up like a deck. Swipe or drag the top card left or right (mouse, touch, or pen), or use the arrows, the dots, or the arrow keys. Add data-lz-stack to the wrapper and it works without extra JavaScript. Only the top card is reachable by keyboard and screen readers; the cards behind it are hidden and inert. Set the height with --stack-h. Motion is skipped when the system asks for reduced motion.

Theme, ripple, and hover

Small behaviors that apply to the whole theme.

Dark mode

The choice is stored in localStorage (lz.theme). Values: light, dark, auto (follows the system). Try the Light / Dark switch at the top of this page.

Code only. Open the JS tab.

Ripple

Buttons, menus, tabs, chips, and other clickable items show a ripple at the click point. To add it to a new element, add its selector to the RIPPLE list in lz.js. To turn it off for one element, add data-no-ripple. It is off when the system asks for reduced motion.

Page fade-in

The content area (.app-content and the right panel) fades in once the page is ready, so widgets built by JavaScript do not flash in half finished. The sidebar, header, and footer stay visible. This comes from theme-init.js in <head>, so keep that script on every page. Change the duration with .app-content, .app-right { transition: opacity .45s ease; } in theme.css. It is skipped when the system asks for reduced motion.

Hover and focus

For custom components use the same tokens so they match: background: var(--lz-hover) and color: var(--lz-primary-ink) on hover, and box-shadow: var(--lz-focus) on :focus-visible. Do not underline links.
